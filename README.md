# Pasta AI

Ciao bella! This is a simple web application that uses a custom-trained Teachable Machine model to identify different types of pasta from an image.

## Features

- **Image Recognition**: Identifies up to 19 different types of pasta.
- **Two Input Modes**: Use your device's camera or upload a photo.
- **Instant Freezing**: The camera scan automatically freezes on a confident prediction, allowing you to read the details.
- **Detailed Information**: Displays the pasta's name, pronunciation, history, typical pairings, meaning, and region of origin.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Machine Learning**: [TensorFlow.js](https://www.tensorflow.org/js) & [Teachable Machine](https://teachablemachine.withgoogle.com/)

## Deployment

This project is set up as a static site and is ready for deployment on platforms like Vercel or Netlify. No build step is required.
